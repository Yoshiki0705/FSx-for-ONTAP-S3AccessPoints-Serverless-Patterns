# 파일 포털 — 보안 및 컴플라이언스 담당자 가이드

> 🌐 Language: [English](../en/portal-compliance-guide.md) | [日本語](../ja/portal-compliance-guide.md) | **한국어** | [简体中文](../zh-CN/portal-compliance-guide.md) | [繁體中文](../zh-TW/portal-compliance-guide.md) | [Français](../fr/portal-compliance-guide.md) | [Deutsch](../de/portal-compliance-guide.md) | [Español](../es/portal-compliance-guide.md)

보안 담당자, 컴플라이언스 분석가, 데이터 보호 담당자가 스토리지 관리 없이 포털을 통해 규제 통제를 **검증**하기 위한 가이드입니다. `storage-admin` 권한은 필요하지 않습니다 — 아래 모든 작업은 읽기 전용 접근으로 수행됩니다.

---

## 포털에서의 역할

| 할 수 있는 작업 | 포털 위치 |
|----------------|-----------|
| 랜섬웨어 보호 상태 확인 | 사이드바 → 🛡️ ARP/AI |
| 스냅샷 잠금 및 보존 기간 확인 | 사이드바 → 🔒 Lock |
| 감사 추적 검토 (누가 무엇에 접근했는지) | 사이드바 → 🔍 Audit Trail |
| PHI 가드레일 적용 확인 | 사이드바 → 📂 All Files (`/dicom/` 또는 `/phi/`로 이동) |
| 출력 버킷의 S3 Object Lock 확인 | 사이드바 → 🔒 Lock → S3 Object Lock 탭 |
| EMS 알림 보기 (ONTAP 시스템 이벤트) | Admin → Resources (`storage-admin`이 아니면 읽기 전용) |

> **참고**: 설정을 변경할 수 없습니다 (잠금 설정, ARP 상태, 내보내기 정책). 변경이 필요하면 `storage-admin` 사용자에게 요청하세요.

---

## 작업 1: 랜섬웨어 보호 확인 (ARP/AI)

**규제 컨텍스트**: FISC, NIST CSF DE.CM-4, ISO 27001 A.12.2

1. 사이드바에서 **🛡️ ARP/AI**를 클릭합니다
2. 모니터링되는 각 볼륨이 녹색 상태(🟢 위협 없음)인지 확인합니다
3. 위협 배지(🔴)가 표시되면 볼륨 이름과 탐지 타임스탬프를 기록합니다
4. **인시던트 라이프사이클 배지**에서 현재 대응 단계를 확인합니다:
   - 🔴 탐지됨 — 위협 식별됨, 격리 대기 중
   - 🟠 격리됨 — 공격자 접근 차단됨, 스냅샷 보존됨
   - 🟡 조사 중 — 포렌식 분석 진행 중
   - 🟢 해결됨 — 인시던트 종료

**감사자를 위한 증빙**: 모든 볼륨의 보호 상태 + 활성 인시던트 배지와 타임스탬프가 표시된 ARP 패널을 스크린샷합니다.

---

## 작업 2: 스냅샷 불변성 확인 (WORM)

**규제 컨텍스트**: SEC 17a-4, FISC 7년 보존, HIPAA 6년, SOX 5년, NARA

1. 사이드바에서 **🔒 Lock**을 클릭합니다
2. 세 개의 탭을 검토합니다:

### 탭 A: ONTAP SnapLock
- 볼륨 유형 확인: **Compliance** (루트 포함 누구도 삭제 불가) 또는 **Enterprise** (관리자가 해제 가능)
- 보존 기간이 정책과 일치하는지 확인:
  - 최소 기간 ≥ 규제 요건
  - Compliance Clock이 초기화되어 실행 중

### 탭 B: S3 Object Lock
- 출력 버킷에 Object Lock이 활성화되어 있는지 확인
- 모드 확인: 규제 아카이브용 **Compliance**, AI 출력용 **Governance**
- 기본 보존 일수가 요건과 일치하는지 확인

### 탭 C: Tamperproof Snapshots
- 잠긴 스냅샷 테이블 검토: 이름, 생성 시간, 만료 시간
- 만료 날짜가 규제 보존 요건과 일치하는지 확인:

| 규제 | 필수 보존 기간 | 예상 만료 |
|------|---------------|-----------|
| FISC | 7년 (2,557일) | 생성 + 7년 |
| HIPAA | 6년 (2,192일) | 생성 + 6년 |
| SOX/J-SOX | 5년 (1,825일) | 생성 + 5년 |
| NARA | 3-75년 (가변) | 기록 일정에 따름 |

**감사자를 위한 증빙**: 잠금 상태 + 보존 기간이 표시된 각 탭을 스크린샷합니다.

---

## 작업 3: 감사 추적 검토

**규제 컨텍스트**: FISC, SOX Section 302/404, HIPAA §164.312(b), PCI DSS 10.x

1. 사이드바에서 **🔍 Audit Trail**을 클릭합니다
2. 패널에 S3 Access Point에 대한 CloudTrail S3 데이터 이벤트가 표시됩니다
3. 검토할 주요 필드:
   - **누가**: IAM 프린시펄 (Cognito 사용자 ID)
   - **언제**: 이벤트 타임스탬프 (UTC)
   - **무엇을**: API 액션 (`GetObject`, `PutObject`, `ListObjectsV2`)
   - **어떤 파일**: S3 키 (파일 경로)
4. 특정 인시던트를 조사하는 경우 날짜 범위 또는 사용자로 필터링합니다

**감사자를 위한 증빙**: 검토 기간으로 필터링된 감사 추적을 내보내거나 스크린샷합니다.

---

## 작업 4: PHI 가드레일 확인

**규제 컨텍스트**: HIPAA §164.502 (최소 필요 원칙), 45 CFR 164.514

1. 사이드바에서 **📂 All Files**를 클릭합니다
2. `/dicom/`, `/phi/`, `/pii/`, 또는 `/hipaa/`라는 이름의 폴더로 이동합니다
3. AI 처리 버튼에 **🚫 PHI — AI Blocked**가 표시되는지 확인합니다
4. 버튼이 비활성화되어 있는지 확인합니다 (사용자 역할에 관계없이 클릭 불가)

**의미**: 이 보호 경로의 파일은 외부 AI 서비스 (Bedrock, Rekognition, Textract, Comprehend)로 전송되는 것이 구조적으로 차단됩니다. 이는 경로 패턴 매칭을 통해 UI 레이어에서 적용되며 어떤 사용자도 재정의할 수 없습니다.

**제한사항**: 이 가드레일은 폴더 명명 규칙에 의존합니다. 보호되지 않는 경로에 배치된 PHI 콘텐츠를 포함한 파일은 차단되지 않습니다. 조직의 폴더 구조 정책이 업스트림에서 적용되도록 하세요.

**감사자를 위한 증빙**: `/dicom/` 폴더에서 비활성화된 AI 버튼을 보여주는 스크린샷.

---

## 작업 5: AI 출력에 대한 S3 Object Lock 확인

**규제 컨텍스트**: SEC 17a-4(f), CFTC 1.31, FINRA 4511

1. **🔒 Lock** → **S3 Object Lock** 탭을 클릭합니다
2. 확인사항:
   - 출력 버킷에 Object Lock이 **활성화**되어 있음
   - 모드가 적절함: 규제 아카이브용 **Compliance** (불변) 또는 AI 출력용 **Governance** (권한으로 재정의 가능)
   - 기본 보존 기간이 보존 일정과 일치
3. Object Lock이 구성되지 않은 경우 `storage-admin` 사용자에게 에스컬레이션합니다

**이것이 중요한 이유**: S3에 저장된 AI 처리 결과 (분류 레이블, 추출된 텍스트, 컴플라이언스 보고서)가 그 자체로 규제 기록이 될 수 있습니다. Object Lock은 이러한 출력이 보존 기간 동안 변경되거나 삭제될 수 없도록 보장합니다.

---

## 작업 6: 인시던트 대응 검증

랜섬웨어 인시던트가 탐지되면:

1. **🛡️ ARP/AI** → 인시던트 배지 상태를 확인합니다
2. 격리가 실행되었는지 확인합니다:
   - 스냅샷 촬영됨 (증거 보존)
   - 의심 사용자/IP 차단됨
3. **🔍 Audit Trail** → 탐지 타임스탬프 전후의 이벤트를 필터링합니다
4. 타임라인을 문서화합니다: 탐지 시간 → 격리 시간 → 조사 시작
5. 해결 후 인시던트 배지가 🟢 해결됨으로 표시되는지 확인합니다

**인시던트 타임라인 SLA 참조**:

| 단계 | 일반적 소요 시간 | 귀사 SLA |
|------|:---:|:---:|
| 탐지 → 격리 | < 5분 (자동) | _____ |
| 격리 → 조사 시작 | < 1시간 | _____ |
| 조사 → 해결 | 사안에 따라 다름 | _____ |
