# ファイルポータル — ユーザーガイド

> 🌐 Language: [English](../en/portal-user-guide.md) | **日本語** | [한국어](../ko/portal-user-guide.md) | [简体中文](../zh-CN/portal-user-guide.md) | [繁體中文](../zh-TW/portal-user-guide.md) | [Français](../fr/portal-user-guide.md) | [Deutsch](../de/portal-user-guide.md) | [Español](../es/portal-user-guide.md)

デプロイ済みのファイルポータルに招待されたエンドユーザー向けのガイドです。管理者がデプロイとアカウント作成を完了していることを前提としています。AWS CLI やデプロイの知識は不要です。

**このポータルでできること**: VPN や SMB/NFS クライアントのセットアップなしに、ブラウザから NAS ファイルの閲覧、AI/ML 分析の実行、結果確認、データ保護状態の確認が行えます。

---

## はじめに

### 1. サインイン

1. 管理者から提供されたポータル URL を開く
2. メールアドレスとパスワードを入力（管理者から提供、または自己登録）
3. MFA が有効な場合は、認証アプリの TOTP コードを入力
4. 初回ログイン時には **Welcome Modal** が表示され、3 つの主要機能をガイドします:
   - 📂 ファイルブラウジング — ブラウザから NAS ファイルを閲覧
   - ⚡ AI 処理 — ファイルを選択してワークフローを起動
   - 🔒 データ保護 — スナップショット、ロック、ランサムウェア対策

> **ヒント**: 「次回から表示しない」にチェックを入れると、以降のログインで Welcome Modal をスキップできます。

### 2. 画面構成

```
┌─────────────────────────────────────────────────────────┐
│ [☰] File Portal              🌐 JA ▾   user@example.com │
├───────────────┬─────────────────────────────────────────┤
│ サイドバー    │  メインコンテンツ                        │
│ (ナビゲーション) │                                      │
│               │                    AI アシスタントパネル →│
└───────────────┴─────────────────────────────────────────┘
```

- **左サイドバー**: Browse、AI & Processing、Data Protection、Admin の 4 グループ
- **メインコンテンツ**: サイドバーで選択中のセクション
- **右パネル**: AI アシスタント（All Files でファイルを選択すると表示）
- **トップバー**: 言語切替、ユーザーメール、サインアウト

### 3. 言語切替

トップバーの 🌐 言語セレクターをクリックして、8 言語を切り替えられます: 日本語, English, 한국어, 简体中文, 繁體中文, Français, Deutsch, Español。ページリロードなしで即座に反映されます。

## Browse — ファイル操作

### All Files

メインのファイルブラウザです。FSx for ONTAP ボリュームの内容が S3 Access Point 経由で表示されます。

| 操作 | 方法 |
|------|------|
| フォルダ移動 | フォルダ名をクリック |
| 上の階層に戻る | ファイル一覧先頭の `..` をクリック |
| 画像プレビュー | 画像ファイル横の 🖼️ アイコンをクリック |
| PDF プレビュー | 📕 アイコンをクリック — ブラウザ内蔵ビューアで表示 |
| Word ドキュメントプレビュー | 📝 アイコンをクリック — ブラウザ内でレンダリング |
| ファイルダウンロード | 📄 アイコンをクリック |
| 共有リンク作成 | 🔗 クリック → TTL 選択 (5 分 / 15 分 / 1 時間) → URL コピー |
| AI に質問 | ファイルを選択 → 右パネルの AI アシスタントに質問を入力 |
| 画像の物体検出 | 画像を選択 → AI パネルの「Detect Objects」をクリック |
| フォルダを処理 | ファイル一覧上部の ⚡ ボタンをクリック |

**PHI 保護フォルダ**: `/dicom/`、`/phi/`、`/pii/` などのフォルダに移動すると、AI 処理ボタンが `🚫 PHI — AI ブロック` と表示されます。これはセーフティガードレールであり、権限に関係なくこれらのフォルダのファイルを AI サービスに送信することはできません。

### お気に入り

ファイル一覧の ⭐ アイコンをクリックしてピン留めしたファイルが表示されます。よく使うファイルへのショートカットとして利用できます。

### 最近のファイル

最近閲覧・ダウンロード・AI クエリしたファイルが相対時間（「3 分前」「2 時間前」）で表示されます。自分の履歴のみが表示され、他のユーザーの履歴は見えません。

### アップロード

Storage Browser for S3 によるドラッグ＆ドロップアップロード。以下も可能です:
- フォルダ作成
- ファイルのコピーと削除
- 複数ファイルの同時アップロード（1 ファイルあたり最大 50 GB）

## AI & Processing — AI 処理

### AI Processing

フォルダやファイルセットに対して AI/ML ワークフローを起動します。

1. ドロップダウンから処理パターンを選択（例: 法務コンプライアンス、金融 IDP、半導体 EDA）
2. 入力パス（プレフィックス）を設定（All Files から ⚡ をクリックした場合は自動入力済み）
3. **Start Processing** をクリック
4. Job History にリダイレクトされ、5 秒ごとにステータスが更新されます

### Job History

過去の処理ジョブの一覧。ステータス、タイムスタンプ、出力データを確認できます。

| ステータス | 意味 |
|-----------|------|
| 🔵 RUNNING | 処理実行中 |
| 🟢 SUCCEEDED | 完了 — クリックで結果表示 |
| 🔴 FAILED | エラー発生 — 出力で詳細を確認 |
| ⚪ TIMED_OUT | 最大実行時間超過 |

ジョブをクリックすると出力が展開されます。結果がボリュームに書き戻された場合は、All Files の出力フォルダへのナビゲーションリンクが表示されます。

### Analytics

Amazon Athena を使った SQL クエリの実行。事前に管理者が Glue Data Catalog テーブルを設定している必要があります。

```sql
-- 例: 拡張子別のファイル数カウント
SELECT extension, COUNT(*) as file_count
FROM your_catalog.file_metadata
GROUP BY extension
ORDER BY file_count DESC
```

### AI エージェント（管理者による有効化が必要）

自然言語でファイル操作ができる AI チャットインターフェースです。Bedrock Converse + tool_use を使用し、ファイルの検索・読取・分析が可能です。

> この機能は管理者が「AI 設定」で有効化した場合のみ表示されます。

**3 つのモード**:
| モード | 用途 |
|--------|------|
| 🧠 KB 検索 | Knowledge Base によるファイル内容のセマンティック検索 |
| 📁 ファイル操作 | ディレクトリ一覧、ファイル検索、読み取り |
| 🤖 マルチエージェント | 全機能（KB + ファイル操作 + 安全制御） |

**主な機能**:
- カードグリッドから定番タスクをワンクリックで開始
- 📎 画像添付 → AI が画像内容を解析して回答
- 📜 会話履歴 → 過去のセッションを復元可能
- 📂 ファイルサイドバー → 参照ファイルの NFS/SMB 権限を表示
- ツール実行トレース → どのエージェントが何を実行したか可視化

### エージェント管理（管理者による有効化が必要）

カスタムエージェントの作成・管理とマルチエージェントチームの構成ができます。

- **エージェント一覧**: 登録済みエージェントのカードグリッド（検索・フィルタ付き）
- **エージェント作成**: アイコン、名前、システムプロンプト、使用ツール、カテゴリを設定
- **チーム作成**: 複数のエージェントを選択し、役割 (Supervisor/Collaborator/Reviewer) を割り当て

### ファイル検索（管理者による有効化が必要）

Bedrock Knowledge Base を利用したセマンティック検索です。ファイル内容の意味に基づいて検索できます。

- **キーワードモード**: ファイル名のパターンマッチ
- **セマンティックモード**: ベクトル検索（KB 構築が必要）

## Data Protection — データ保護

### Snapshots

ボリュームスナップショット（データのポイントインタイムコピー）を表示します。

- **一覧**: 利用可能なスナップショットと作成日時
- **復元**: 「Restore」をクリックすると FlexClone（即時・容量効率の良いコピー）が作成されます。クローンには専用の S3 Access Point が付与され、数秒で利用可能になります。

### Lock (WORM)

データの不変性ステータスを 3 つのメカニズムで確認できます:

| タブ | 表示内容 |
|-----|---------|
| ONTAP SnapLock | ボリュームの Compliance/Enterprise モード、保持期間 |
| S3 Object Lock | AI 出力バケットのオブジェクトレベル WORM 設定 |
| Tamperproof Snapshot | ロック済みスナップショットと有効期限 |

> **注意**: ロック設定の変更には `storage-admin` ロールが必要です。一般ユーザーはこのセクションの閲覧のみ可能です。

### ARP/AI（ランサムウェア保護）

ボリュームのランサムウェア自動保護ステータスを確認します。

| 表示内容 | 意味 |
|---------|------|
| 🟢 脅威なし | 全ボリュームが正常 |
| 🔴 脅威検知 | ARP/AI が不審なアクティビティを検知 |
| インシデントバッジ | 現在の対応段階を表示（検知 → 封じ込め → 調査中 → 解決済み） |

脅威が検知され、`storage-admin` グループに所属している場合は、このパネルから直接封じ込めアクションを実行できます。

## Admin（`storage-admin` グループが必要）

以下のセクションは `storage-admin` Cognito グループに所属するアカウントのみ表示・操作可能です。

### Storage Dashboard

管理者のランディングページ。4 枚のカードで表示:
- 💾 ボリューム数 + 平均容量使用率
- 🛡️ ARP 保護対象ボリューム + アクティブな脅威数
- 🔐 ロック済み（改ざん防止）スナップショット数
- 📊 ストレージ効率比率

カードをクリックすると詳細パネルに遷移します。

### Resources

カード型グリッドの管理パネル。3 カテゴリ × 10 の管理領域:

| カテゴリ | パネル |
|---------|--------|
| Storage | Volumes, Qtrees, Quotas, Efficiency |
| Access Control | Export Policies, CIFS Shares, QoS |
| Protection | ARP Admin, Snapshot Admin, SnapLock |

### Version Diff

2 つのスナップショット間でファイル内容を並べて比較します。

### Audit Trail

CloudTrail S3 データイベントをクエリして「誰が、いつ、何にアクセスしたか」を確認します。

### 4. スマートフォンで使う

> 📱 **画面ごとのスクリーンショット付きで手順を追いたい場合は、[スマートフォン操作ガイド](portal-mobile-guide.md) を参照してください。**
> この節は要点のみです。

専用アプリはありません。**デスクトップと同じ URL** をスマートフォンのブラウザで開きます
（iOS の Safari、Android の Chrome で確認しています）。

<img src="../../solutions/amplify-portal/docs/screenshots/portal-files-mobile-dark.png" alt="スマートフォンでのファイル一覧（ダークテーマ）" width="300">

**手順**

1. 管理者から受け取った URL をブラウザで開く
2. サインインする（メールアドレスとパスワード、MFA が有効なら TOTP コード）。
   パスワード管理アプリの自動入力がそのまま使えます
3. 画面の上端に **☰**、テーマ切替、言語切替、サインアウト（⏻）が並びます。
   サイドバーは初期状態では隠れています
4. **☰** をタップするとナビゲーションが本文の上に開きます。セクションを選ぶと自動で閉じます。
   選ばずに閉じるときは、暗くなった部分をタップします
5. ファイルを開くには行のアイコン（📄 / 🖼️ / 📕 / 📝）をタップします。
   プレビューは画面下から立ち上がるシートで開き、**✕** で閉じます
6. 複数のファイルをまとめて扱うときは、行左端のチェックボックスをタップします。
   選択件数と操作（ゴミ箱へ移動など）が一覧の上に出ます

**デスクトップとの違い**

| 項目 | スマートフォンでの扱い |
|------|--------------------|
| サイドバー | 本文の上に重なるドロワー。**☰** で開閉 |
| 「サイズ」「更新日時」列 | 画面幅が足りないため省略。並べ替えは「名前」で行えます |
| メールアドレスの表示 | 省略（サインアウトはアイコンのみ） |
| ファイルプレビュー | 画面下からのシート（最大で画面の 7 割）。PDF は横向きにすると読みやすくなります |
| AI アシスタントパネル | 右からの引き出しとして開きます |

> **テーマの 🖥️ について**: これは「PC 表示に切り替える」ボタンではありません。
> ☀️ ライト / 🌙 ダーク / 🖥️ **端末の設定に合わせる** の 3 択で、🖥️ を選ぶと
> iOS や Android の外観設定（夜間の自動切替を含む）に追従します。

> **通信量の注意**: フォルダーの ZIP ダウンロードはフォルダー配下をまとめて転送します。
> モバイル回線では対象の件数とサイズを確認してから実行してください。

## よくある質問

**Q: 一部のパネルに「ONTAP 接続が必要です」と表示されます。**
A: ポータルが DemoMode で動作しているか、管理者が VPC 接続を設定していない状態です。ファイルブラウジングと AI 機能は動作します。ONTAP 固有のパネル（Snapshots、ARP、Lock）のみ接続が必要です。

**Q: AI 処理ボタンが「PHI — AI ブロック」と表示されます。**
A: 保護対象フォルダ（`/dicom/`、`/phi/`、`/pii/` 等）にいます。これは意図的な設計です。AI 機能を使うには、保護対象外のフォルダに移動してください。

**Q: 共有リンクがすぐに期限切れになります。**
A: 共有リンクは選択した有効期限（5 分、15 分、1 時間）の Presigned URL を使用しています。より長期の共有が必要な場合は、管理者に Nextcloud 連携について相談するか、TTL オプションの調整を依頼してください。

**Q: NFS/SMB でアップロードしたファイルが表示されません。**
A: ONTAP はクロスプロトコルの強整合性を保証しているため、即座に反映されるはずです。ファイル一覧をリフレッシュしてみてください。それでも表示されない場合、サブフォルダにある可能性があります。パスを確認してください。

**Q: モバイルで使えますか？**
A: はい。手順は「はじめに」の「4. スマートフォンで使う」にあります。

**Q: パスワードを変更したいです。**
A: Cognito Hosted UI を使用するか、管理者に以下のコマンドでリセットを依頼してください:
```
aws cognito-idp admin-set-user-password --user-pool-id <pool-id> --username <your-email> --password <new-password> --permanent
```
