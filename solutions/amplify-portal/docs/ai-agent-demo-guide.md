# AI エージェント デモガイド

🌐 **Language / 言語**: **日本語** | [English](ai-agent-demo-guide.en.md)

> 管理者による AI 機能の有効化から、エンドユーザーの利用までを E2E で確認するためのガイドです。

## 前提条件

- Amplify sandbox がデプロイ済み (`npx ampx sandbox --once`)
- Cognito ユーザーが `storage-admin` グループに所属（AI 設定のトグル操作に必要）
- (セマンティック検索を使う場合) Bedrock Knowledge Base が作成済み、`portal-config.ts` に KB ID が設定済み

## デモシナリオ

### シナリオ 1: AI 機能の有効化 (管理者)

1. サイドバー「管理 > リソース管理」を選択
2. 「AI サービス」カテゴリの「AI 設定」カードをクリック
3. コスト情報を確認:
   - AI エージェント: ✅ 即時利用可能 (~$0.001/リクエスト)
   - セマンティック検索: ⚙️ KB 構築必要 (~$1-10/月 S3 Vectors)
4. 「AI エージェント」トグルを ON → ナビに「🤖 AI エージェント」が即座に表示
5. (オプション) 「セマンティック検索」トグルを ON
6. ページをリロード → 設定が永続化されていることを確認

### シナリオ 2: AI エージェントでファイル操作

1. サイドバー「AI & 処理 > AI エージェント」を選択
2. モードセレクター: 「📁 ファイル操作」を選択
3. カードグリッドから「フォルダを探索」をクリック → エージェントがルートフォルダ一覧を返す
4. 「simulation/ のログファイルを検索して」と入力 → search_files ツール実行
5. ツールトレースのタイムラインで `file-explorer` (青) バッジを確認
6. 📜 ボタン → 会話履歴パネルが開く（自動保存されている）

### シナリオ 3: マルチモーダル画像入力

1. モードセレクター: 「🤖 マルチエージェント」を選択
2. 📎 ボタンをクリック → 画像ファイルを選択（または入力欄にドラッグ＆ドロップ）
3. プレビューが表示される → 「この画像に写っているものを説明して」と入力
4. Bedrock Vision API が画像を解析し回答を生成

### シナリオ 4: KB モードでセマンティック検索

1. モードセレクター: 「🧠 KB 検索」を選択
2. カードグリッドが KB 関連カードのみ表示
3. 「熱設計の温度上限について教えて」と入力
4. kb_search ツールが実行 → `knowledge-analyst` (紫) バッジ
5. 回答にソースファイルパスの Citation が表示

### シナリオ 5: ファイル権限サイドバー

1. エージェントとの会話でファイルが参照された後
2. 📂 ボタンをクリック → ファイルサイドバーが展開
3. 参照されたファイルのチップをクリック
4. セキュリティスタイル、Owner/Group、UNIX パーミッション、ACL が表示

### シナリオ 6: エージェント管理 (Agent Directory)

1. サイドバー「AI & 処理 > エージェント管理」を選択
2. 「エージェント一覧」タブ → カードグリッドが表示（初回は空）
3. 「+ 新規作成」ボタン → Agent Creator フォーム
4. 入力:
   - アイコン: 🔬
   - 名前: ログ分析エージェント
   - 説明: シミュレーションログの分析に特化
   - カテゴリ: analytics
   - システムプロンプト: 「あなたはシミュレーションログの分析専門家です...」
   - ツール: read_file, search_files にチェック
   - 共有: ON
5. 「エージェントを作成」→ ディレクトリに戻る → カードが表示される

### シナリオ 7: マルチエージェントチーム作成

1. 「🧩 マルチエージェントチーム」タブを選択
2. 「+ チーム作成」→ ウィザードが開く
3. 入力:
   - チーム名: ドキュメント分析チーム
   - 説明: 技術文書の検索と要約
4. エージェントプールから 2 つ以上選択
5. 各エージェントに役割を割り当て (Supervisor / Collaborator / Reviewer)
6. 「チーム作成」→ ギャラリーにチームカードが表示

## 確認ポイント

| 機能 | 確認方法 | 期待結果 |
|------|---------|---------|
| AI 設定トグル | ON/OFF 切替 | ナビ項目が即座に表示/非表示 |
| モード切替 | ピルセレクター切替 | カードグリッドとプロンプトが変化 |
| 会話履歴 | 📜 パネル | 過去のセッション一覧、クリックで復元 |
| 画像アップロード | 📎 or D&D | プレビュー表示、Vision回答 |
| ファイルサイドバー | ファイル参照後 📂 | 権限情報（ONTAP接続時） |
| Agent Directory | カードグリッド | 検索、カテゴリフィルタ、詳細パネル |
| Agent Creator | フォーム入力 | バリデーション、作成成功 |
| Teams ウィザード | エージェント選択+役割 | チーム作成、ギャラリー表示 |

## トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| AI 設定トグルでエラー | Lambda 未デプロイ | `npx ampx sandbox --once` 再実行 |
| ナビに AI エージェントが出ない | 設定未有効化 or 非admin | storage-admin グループ確認 → AI 設定で ON |
| KB 検索で "not configured" | bedrockKbId 未設定 | portal-config.ts に KB ID を設定 → 再デプロイ |
| 画像アップロードでエラー | 5MB 超 or 非対応形式 | jpeg/png/gif/webp、5MB 以下で再試行 |
| ファイルサイドバーが空 | ONTAP 未接続 | VPC Lambda + ONTAP 管理 LIF 接続が必要 |
