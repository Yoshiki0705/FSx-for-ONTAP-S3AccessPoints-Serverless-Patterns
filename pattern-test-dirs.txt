# Pattern directories whose tests are run, one per line.

# Read by BOTH the Makefile `test` target and .github/workflows/ci.yml, because
# those two kept their own hand-maintained lists and drifted apart. CI listed 37
# directories, the Makefile reached 16, and 13 directories with passing tests —
# about 790 tests — were in neither, so they never executed anywhere. Adding a
# pattern meant remembering two places, and forgetting one was silent.
#
# Each directory gets its own pytest process. Many patterns ship a functions/
# package with colliding module names (functions.discovery in every one of them),
# so a single combined invocation raises ModuleNotFoundError once sys.modules
# caches the first pattern's package. See AGENTS.md, "from functions.xxx import
# collision in batch test runs".
#
# Excluded on purpose:
#   solutions/event-driven/fpolicy   tests/ holds only an empty __init__.py, so
#                                    pytest collects nothing and exits 5, which
#                                    fails the loop under `set -e`. Add it here
#                                    once it has a test.
#
# `shared/`, `scripts/` and `operations/` as a whole are invoked separately by the
# Makefile and by CI; the per-pattern operations/ entries below are the individual
# OPS patterns.
