# Diagrams below the readability floor. Read by scripts/check_diagram_fonts.py.
#
# This file may only shrink. An unlisted violation fails the gate, and so does a listed file that
# now meets the floor -- which is what forces a line out when a diagram is fixed. Adding a line is
# possible but never quiet: it lands in the diff beside the diagram that needed it.
#
# All of these predate the gate, and all four figures are hand-authored XML rather than built from
# a spec -- which is why they outlasted the generated Part2 and Part3 set.
#
# The numbers below were wrong until the sources were renamed to match their exports. The gate finds
# an export by matching the source's stem, and these four were named `file-portal-*` and
# `nextcloud-only-*` while their exports carried the names the documents reference, so the lookup
# missed and the gate fell back to `pageWidth`. That is the page, not the picture: draw.io crops to
# content and adds a border, so it was reporting these at 6.5 to 10.8px when a reader receives them
# at 4.4 to 8.1px. The real widths, and what each would need at its current width:
#
#   architecture-overview        1190px  ->  fontSize 19
#   nextcloud-external-storage   1734px  ->  fontSize 28
#   amplify-vpc-split            1990px  ->  fontSize 32
#   coexistence-3path            2214px  ->  fontSize 36
#
# So the answer is not a font bump. Each carries a notes box, and each is 21 to 48 cells wide in one
# row; the order to work through is the one in docs/agent/diagram-regeneration.md -- move the notes
# box into the prose, fold labels to two lines, narrow the canvas toward 880px and stack vertically,
# then split.
#
# The remaining decision is not a layout decision: whether these four move into the declarative
# builder that Part2 and Part3 use. That builder derives the label size from the width it ends up at,
# so a figure inside it cannot fall below the floor again, and these four are the last hand-authored
# figures left. Porting them is larger than relaying them out by hand and it is the only version of
# this fix that does not have to be repeated.
#
